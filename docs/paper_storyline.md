> **状态**：2026-09-29 重写，取代旧的"四幕 / 5 命题"版本（旧版见 git 历史，commit 273db5d 之前）。

**一句话主线**：agent 替用户填写了一个没被指定的离散参数；LLM 在这种情况下会自信而一致地取自己的默认值；
接口只检查合法性，任何不查询替代取值的检查都不可能可靠；决策会不会因此改变，由决策几何 (ρ, κ) 决定；
把所有合法取值当作版本空间、只在其上决策一致时放行，是唯一可靠且放行最多的规则，而它的代价只由数据决定、与模型无关。

## 一、设定：接口检查"合法"，正确性是"关系"

用户给出任务 `x`，决策涉及实体 `S_x = {s_1, …, s_n}`。工具有一个离散参数，合法取值为有限集 `P`（schema 中 enum 的乘积）。工具返回

```
y_s(p) = g(s, p),     s ∈ S_x,  p ∈ P
```

决策是返回值的函数：

```
D_x(p) = δ( y_{s_1}(p), …, y_{s_n}(p) )
  排序型: δ = top-k 集合
  阈值型: δ = { s : y_s > T }
```

agent（参数为 θ 的 LLM）填写 `p̂`；一般地可对不同实体填不同的值，记 `p̂ ∈ Pⁿ`。任务需要的取值为 `p*(x)`，与任务文本相容的取值集合为
`Θ(x) ⊆ P`。**真实场景中用户只下达任务、不提参数（他不知道参数存在，更不知道哪里会出错），所以 `Θ(x) = P`**，p\* 无法从 x 辨识。

```
合法性      V(p̂)    = 1[ p̂ ∈ P ]
参数正确    R(x, p̂) = 1[ p̂ = p*(x) ]
决策正确    C(x, p̂) = 1[ D_x(p̂) = D_x(p*) ]
```

`V = 1` 推不出 `R = 1`，`R = 0` 也推不出 `C = 0`。论文关心的是 C。

## 二、生成：LLM 为什么会自信地填错

**隐式贝叶斯推断（Xie et al., ICLR 2022）**：

```
π(p | x) = Σ_c π(p | c) · π(c | x),      π(c | x) ∝ π(x | c) · π(c)
```

x 不含期间信息时，对只在期间上不同的概念 `π(x | c)` 为常数，于是 `π(p | x) = π(p)`：后验退回先验。
Xie 的 Theorem 2 以"不可区分的概念产出相似输出"兜底，但 quarter 与 fy 返回不同数值，恰好落在兜底之外（该推论是我们的）。

**后训练锐化（Verbalized Sampling, arXiv 2510.01171；Kirk et al., ICLR 2024）**：奖励含典型性偏置 `r = r_true + α·log π_base`（α̂ ≈ 0.57–0.65），KL 约束下

```
π_θ(p | x) ∝ π_base(p | x)^γ · exp(r_true / β),     γ = 1 + α/β > 1
```

期间未说明时 `r_true` 打平，`π_θ ∝ π_base^γ`：argmax 不变、熵下降，模型稳定地取默认值 `p_θ^def = argmax_p π_base(p)`。
偏好训练还奖励"直接回答"而非提问（Zhang, Knox & Choi, ICLR 2025；Zhao et al. 2026）。

**推论**：
1. 错误与任务无关：x 不含期间信息时，`1[p̂ ≠ p*] = 1[p_θ^def ≠ p*]`。
2. 自一致性失效：k 次采样全同的概率为 `Σ_p π_θ(p|x)^k`，分布越尖越接近 1，"不一致才报警"不会报警。

**证据**：
- 未写明期间时错误率 56–98%，写明时 ≈ 0（S7、I1）。
- 错误集中于同一个值 77–99%（P2）；选错时 5 次采样全同 42–87%（L1）。
- Qwen2.5 默认 `all`、Qwen3.8 默认 `fy`：`p_θ^def` 由后训练配方决定而非家族（与 Fortier, Chen & West 2026 一致）。

## 三、检测：为什么查不出来

**命题 1（连续认证为空）**：

```
S_cont(ε) = sup_{‖c′ − c‖ ≤ ε} d( f(c′, p̂), f(c, p̂) ),     S_cont(0) = 0
D_G      = max_{p′ ∈ P} d( y(p′), y(p̂) ) > 0
```

连续界在离散替换上恒报"安全"。

**要判定的对象**是反事实谓词

```
Δ(x) = 1[ ∃ p′ ∈ Θ(x) :  D_x(p′) ≠ D_x(p̂) ]
```

**定理 1（必须观察替代结果）**：检查器 ψ 看到 `O = (x, p̂, y(p̂))`，并可向工具查询 `Q ⊆ S_x × P`；称其可靠，若对所有与观测一致的数据 g′，
`ψ = 放行 ⇒ Δ_{g′}(x) = 0`。设 (i) 决策对每个实体敏感；(ii) 不同等价类的数据间无函数约束。若可靠的 ψ 放行 x，则对每个 `C ∌ p̂` 和每个实体 s，
Q 必含某个 `(s, p), p ∈ C`，故

```
|Q| ≥ n · ( |P/∼| − 1 )
```

*证明（对手论证）*：若 `(s, C)` 未被查询，只改 `g(s, p), p ∈ C`：阈值型移到 T 另一侧，排序型移进/移出前 k。观测不变故仍放行，而 `Δ_{g′} = 1`。∎

**推论**：自我验证、强模型裁判、自一致性、多模型投票的 `Q = ∅`，都不可能可靠——信息上不可能，与模型强弱无关。

**LLM 层面**：记 `Y′ = y(Θ(x) ∖ {p̂})`，由数据处理不等式

```
I( ψ(O; θ) ; Y′ )  ≤  I( O ; Y′ ) + I( θ ; Y′ | O )
```

第二项是模型记忆中的知识；某公司某期的具体数值是任意事实，截止后的更是未见，该项有上界（Kalai et al. 2025）。所以检查器可以有信号，但给不出保证；
自我改进"不能创造模型里本来没有的信息"（Huang et al. 2024 Sharpening）。投票：若众数为错值，多数票准确率随 K → ∞ 趋于 0（Chen et al. 2024 Lemma 1）；
两模型都错时 60% 错成同一答案（Kim et al., ICML 2025）。LLM 察觉工具静默错误靠字面特征而非数值（Tools Fail, EMNLP 2024）。

**证据**：所有不查工具的方法都漏错（强模型裁判最多漏 18 个）；裁判 balanced accuracy 0.51–0.58；自查在 3 个模型上有信号但仍漏错；
"信号来自年度 ≈ 季度 × 4"已被证伪（L3），信号来源暂不解释——定理 1 只说"无保证"，不说"无信号"。

## 四、后果：什么时候会翻

```
log y_s(p′) = log y_s(p̂) + μ + ε_s,     E[ε_s] = 0,  sd(ε_s) = σ_r
ρ = σ_r / σ_q          κ = |μ| / σ_q          （σ_q：实体间 log y 的离散度）
```

**命题 2a（排序型）**：令 `U = log y_a − log y_b`，`V = ε_a − ε_b`，

```
flip(a, b)  ⇔  sign(U + V) ≠ sign(U)  ⇔  |V| > |U| 且符号相反
U ~ N(0, 2σ_q²), V ~ N(0, 2σ_r²) 独立  ⇒  P(flip) = (1/π) · arctan ρ
```

μ 在差分中消失。

**命题 2b（阈值型）**：`sign(log y_s − log T) ≠ sign(log y_s + μ + ε_s − log T)`，共同缩放就是全部效应，由 κ 支配。

**经典锚点（测量理论的有意义性，Roberts 1979）**：比率尺度的容许变换群 `G = { y ↦ λy : λ > 0 }`；陈述 φ 有意义当且仅当 `φ(y) = φ(λy)` 对所有 λ 成立。
"y_a > y_b" 在 G 下不变，"y_s > T"（T 固定）不是。μ 是 G 中元素 `λ = e^μ`，ε_s 不属于 G。**命题 2a 的 arctan 公式是我们对有意义性的量化推广。**

**LLM 层面（LLM 亲自决策时）**：LLM 对数量的内部表示近似 `r(y) ≈ a·log y + b`（AlQuabeh et al. 2025；Cacioli 2026），比较带韦伯噪声 σ_c：
排序比较 `r(y_a) − r(y_b)` 中 μ 抵消，阈值比较 `r(y_s) − r(T)` 被平移 `a·μ`。工具返回值不标期间，LLM 缺少单位线索、不会换算（Sasaki et al. 2026）。
**S7-B 验证**：由 gpt-6-luna、deepseek 亲自决策时，quarter→fy 的翻转与代码决策逐题一致 98–99%；三个模型在阈值-流量题上都 100% 翻转
（不会自发年化补救）；口径混用使排序题翻转率升到 96–100%。qwen2.5 的一致率只有 79%，原因是它在同一张表上与代码决策一致仅 15%
（推理噪声，不是口径处理）。

**证据**：流量 `μ̂ ≈ 1.18–1.34`（log 4 = 1.39），存量 `μ̂ ≈ 0`；阈值穿越率流量 40%、存量 8–13%（P1）；`corr(ρ, flip) = +0.79`（排序）、
`corr(κ, flip) = +0.91`（阈值），κ 对排序 ≈ 0（G6–G8）。

## 五、方法：版本空间上一致才放行

```
H_x = { h_p = D_x(p) : p ∈ Θ(x) }
放行(x)  ⇔  | { D_x(p) : p ∈ Θ(x) } | = 1   且   D_x(p̂) 等于这个共同值
```

否则拦截或问用户。实现上用观测等价 `p ∼ p′ ⇔ ∀s: y_s(p) = y_s(p′)`，每类查一个代表，查询 `n · |P/∼|` 次，达到定理 1 的下界。

**命题 3a（可靠性）**：`放行(x) ⇒ ∀ p* ∈ Θ(x): D_x(p̂) = D_x(p*)`——不需要知道 p\*，不依赖任何标注约定。

**命题 3b（逐点最优，El-Yaniv & Wiener 2010 Thm 7）**：若 R 放行 x 时对 Θ(x) 上一切分布 π 都有 `P_{p*~π}(D(p̂) ≠ D(p*)) = 0`，则
`R(x) = 放行 ⇒ ENUM(x) = 放行`。一般化到先验类 Γ（Berger 1994）：

```
R_Γ(x) = 放行  ⇔  sup_{π ∈ Γ}  π( { p : D(p) ≠ D(p̂) } ) ≤ α
```

Γ 越窄放行越多；Γ = 整个单纯形、α = 0 时退化为 ENUM。

**推论（信息价值）**：

```
U(a, p*) = 1[a = D(p*)],   EVPI(x; π) = 1 − max_a π( D(p*) = a )
ENUM 放行  ⇔  ∀π:  EVPI(x; π) = 0
```

放行的恰是"问用户也没用"的决策，拦下的恰是"问用户可能有用"的决策。

**LLM 层面（LLM-Modulo, Kambhampati et al. 2024）**：系统可靠性继承自外部 critic；此处 critic 就是工具执行 g，且 `|Θ(x)| < ∞` 使完备性不依赖 LLM 想全候选。
放行判断不含 `π_θ`，不受 LLM 校准不准（后训练后更差，GPT-4 技术报告 Fig. 8）的影响。

**证据**：真实场景（未写明期间）下，6 个模型 × 2 种读法，ENUM 漏错全为 0（S7）。由 LLM 亲自决策时（S7-B，3 个模型），
ENUM-B 放行的决策中由参数错误导致的错误同样为 0；LLM 自己的推理错误不在保证范围内，单独报告（弱模型 qwen2.5 放行中有 12 个）。

## 六、代价：由数据决定，与模型无关

**命题 4**：放行条件只依赖 `(g, δ, Θ(x))`，不依赖 `π_θ`（唯一例外：agent 对不同实体填了不同的值）。

```
覆盖率        cov   = P_x( |D_x(Θ(x))| = 1 )                与 θ 无关
被拦住的错误  err_θ = P_x( D_x(p̂) ≠ D_x(p*) )               依赖 θ
```

代价由数据决定，收益由模型决定：**模型越差，筛查器越有价值；换更强的模型，拦截负担不变。**

**证据**：192 个实例中 187 个在 6 个模型上放行决定完全相同，其余 5 个全部是某模型混用了期间（L2）。

**放行率预测**（独立近似，H3 已检验）：

```
阈值型:  cov_x ≈ Π_s  P( s 不越过 T )                    κ 越大越小
排序型:  cov_x ≈ Π_{(a,b) ∈ 前 k 边界}  ( 1 − (1/π)·arctan ρ )
```

实测：阈值题放行 0%，排序题 14–25%。**H3**：只用 (ρ, κ, n, k) 预测逐题放行，AUC 0.83 / 0.87（R-first / R-aligned），
数值跳变幅度作预测量只有 0.45 / 0.54；水平校准偏保守（分层误差 8.5 / 10.4 pp）。

## 六½、泛化：第二个金融参数（S10，价格复权）

**问题**：上面的证据全部来自一个参数 `period`（主要是共同缩放 μ，κ 型）。换一个机制不同的真实金融参数，现象、几何与方法是否仍成立？

**参数**：价格复权 `adjustment ∈ {splits_only, splits_and_dividends, unadjusted}`，schema 原样取自 OpenBB（默认 `splits_only`），
数据为冻结的 yfinance 快照（80 只美股，按当时成交价还原经 8 个已知收盘价精确校验）。复权对各公司的影响因股息率与拆股而异
（2020 年初 MO −41%、KO −18%、NVDA −0.7%、AMZN 0%），是**实体特异（ρ 型）**变化，与 `period` 互补；ρ 从约 0.05 到约 1.9 形成剂量梯度。

**结果**（6 个模型 × 48 个实例，用户均未提复权）：
- 生成：模型大量不填该参数，落到 schema 默认值；但问收益率时部分模型会主动改选全复权——默认填写存在，且随题型变化
  （预测 E1"单一默认值 ≥ 70%"只在 2/6 个模型上成立，按判据记为不通过）。
- 后果：决策错误约 45–51%（高于 `period`）；只用 (ρ, κ) 预测放行 AUC 0.945（数值跳变幅度 0.696）。
- 方法：**ENUM 放行 20–27%，6 个模型漏错全为 0**；不查数据的方法合计——自一致性放行 118 错 51、自我验证 105 错 45、
  强模型裁判 98 错 46、**多模型投票 18 错 17**（模型们一致时往往一起错，即第三节的错误相关）。
- 代价：放行决定跨模型不同的 3 个实例全部由混用口径解释（命题 4 再次成立）。

**候选筛选**（均实际下载检查）：SEC EDGAR 财年/自然年效应弱（前 3 名翻转 0.5–2%）且混有重述噪声，不采用；Finance Agent v2（vals-ai）
不作平台，但其 system prompt 写死"always use the raw, unadjusted price … unless the question specifically asks"，可作动机证据；
FinRetrieval 统计期间口径混淆占全部错误 43%，作动机引用。详见 `docs/S10_ADJUSTMENT_PROTOCOL.md`。

## 八、贡献与边界

**我们的**：
- 把"agent 静默填写未指定的离散参数"形式化为 `Θ(x) = P` 下的选择性分类问题；
- 带前提 (i)(ii) 的查询下界（定理 1）及"模型检查不可能可靠"的推论；
- LLM 机制链 `π_θ ∝ π_base^γ` 在该问题上的串联与实证；
- 命题 2a 的 arctan 推广；命题 4（代价与模型无关）。

**归属前人**：命题 3a/3b（El-Yaniv & Wiener；Berger）；命题 2b 的有意义性（测量理论）；定理 1 的两点论证技术（Holland 等）；
LLM 机制各环节（Xie、McCoy、Verbalized Sampling、Kirk、Kalai、Huang、Kambhampati 等）。

**边界**：
- 每个模型只有 21–32 个决策（真实场景、测试字段口径）；全字段重算为 46–64 个并已报 95% 置信上限；ENUM 的零漏错由构造保证，
  证据来源是审计等价的检验（640 单元 0 违反），不是放行样本数；
- 定理 1 的前提 (ii) 在数据上不严格成立（年度 ≈ 四个季度之和），这也是减少查询的方向；
- 自查信号来源未解释；
- H3 的水平校准偏保守（R-aligned 下分层误差 10.4 pp）；S7-B 中弱模型（qwen2.5）推理噪声大；
- S10 中"单一默认值"（E1）不成立：默认填写随题型变化；
- 领域限定金融（`period`、价格复权两个参数）；
- 旧命题"绑定分解 ℓ = a + bu + cv + duv"退出主线（数据中"写明了还选错"几乎不存在），移入讨论。

## 九、写作纪律

- 不把 findata 年度数据滞后（X4，约 455 天）的效应全部归于口径差异。
- 已知结果一律写"是 X 的实例"并引用，不写成自己的定理。
- "用户写明了参数"只作对照组，不作场景。
- 文献只引用已读方法节（✅）的内容；◐/○ 的只作背景或不引。
