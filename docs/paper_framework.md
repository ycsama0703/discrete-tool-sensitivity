## 一句话贡献

现有工具输出的连续敏感度认证（Lipschitz 界 L·ε）在离散工具参数（period/statement/
ticker）翻错时给出 ε=0 → 界=0，**不是"漏掉"误差，而是给 agent 一个虚假安全感**——
agent 会过度信任一个实际跳变 66–72% 的输出。我们提出混合敏感度 S_mix(ε) = L_G·ε +
D_G 显式覆盖离散最坏跳变 D_G，并用纯数据验证（$0、无 LLM）证明这个盲区真实存在、
规模可观、跨端点/参数/symbol 泛化。

**双贡献定位（理论 + 实证）**：
- **理论贡献（修复后）**：S_mix(0) = D_G(0) > 0 = L·0 的结构结论——连续界在 ε→0 时
  无法覆盖离散跃迁。原始推导来自 AlphaGap 流程的 AI 生成（有漏洞），我们复核并修复了
  两处硬伤（L_G 有限性、D_G 对 c' 取 sup），见 2.2。**这是条件性、结构性的理论，不是
  深刻的新数学定理**——它用现成的三角不等式 + Lipschitz，把"连续界漏离散"变成严格的、
  可验证的表述。
- **实证贡献**：验证理论在真实 API 上成立（输出跳 66%）、AI 真的会犯（弱模型
  12–18.75%）、决策真的会翻（80% 排名变）、**决策翻转的充要条件可推导**（边际条件
  $|\Delta\log r|>|\Delta\log q|$，闭式速率 $\frac{1}{\pi}\arctan(\rho)$，4 宇宙
  48 格 MAE 3.16pp、corr(ρ,flip)=+0.851 而 corr(jump,flip) 仅 +0.11）、筛查器能把
  决策错误降到 0。

**卖点是"诊断洞察（认证会骗人）+ 可落地的筛查器"，理论给"为什么"，实证给"确实如此"。**
审稿人若问"数学贡献是什么"：答案是——一个修复后严格成立的结构结论（S_mix(0)=D_G>0），
加上扎实的实证。别把它吹成重大数学创新。

## 1. 定位与动机

### 问题
LLM 工具调用 agent 靠工具输出做决策。工具输出需要**灵敏度认证**：这个输出对输入扰动
有多敏感？现有做法是连续 Lipschitz 界 S_cont(ε) = L·ε，假设错误落在输入的连续邻域内。

### 盲区（核心洞察）
但工具参数是**离散**的（ticker、period、accounting basis、unit）。一个 token 变化就能
从正确调用跳到另一个 schema-valid 调用。对离散替换 z→z'：
- 连续空间里 ε=0（没有连续变化）→ **S_cont(0) = 0**
- 但实际输出可能跳变 66–72%（period=quarter→fy 的 eps 2.04→6.11）

**关键：连续界不是"漏掉"这个误差，而是主动宣称"零误差、很稳"。** 这比没有认证更糟——
agent 会过度信任一个其实会跳变的输出。这是"认证会骗人"的虚假安全感问题。

### 现有工作的盲区（文献定位）
现有工具鲁棒性工作测的都是**行为/检测/风险控制**，没人做**认证的数学完备性**：
- **SilentProbe (2609.00035)**：测 agent 能否察觉参数错误（HTTP 200 但结果错）。测**检测**，不是认证。
- **Beyond Aggregate Risk (2607.24343)**：工具调用 conformal 风险控制。测**风险预算**，不是输出跃迁覆盖。
- **ToolRobustBench (2608.23635)**：扰动鲁棒性评测。测"扰动后是否失败"。
- **Butterfly Effects (2507.15296)**：参数填充失败分类法。测"LLM 会不会填错参数"。
- **No Certificate No Execution (2605.24462)**：agent 认证轨迹。

**盲区**：没有一篇做"连续敏感度认证（Lipschitz 界）在数学上覆盖不到离散工具错误"这个
认证角度。它们测检测/风险控制，我们测认证的完备性。

### 我们的增量
混合敏感度 S_mix(ε) = L_G·ε + D_G，其中 D_G = max_{z'∈N_G(z)} d_Y(f(c,z'), f(c,z))
是离散语义邻接的 worst-case 跃迁。连续界漏掉 D_G，混合界覆盖它。

## 2. 方法

### 2.1 核心对象
对工具调用 x = (c, z)，c 连续（日期、阈值）、z 离散（ticker、period、unit）：
```
S_cont(ε) = sup_{||c'-c||≤ε} d_Y(f(c',z), f(c,z)) ≈ L·ε   # 连续界
D_G       = max_{z'∈N_G(z)} d_Y(f(c,z'), f(c,z))            # 离散最坏跃迁
S_mix(ε)  = L_G·ε + D_G                                     # 混合界
```
对离散替换 z→z'：连续界 ε=0 → S_cont(0)=0，漏掉 D_G；混合界 S_mix(0)=D_G 覆盖。

### 2.2 理论底座（修复后的严格推导）

**来源说明**：原始推导来自 AlphaGap 流程的 AI 生成（`D:\ideas\2026-09-16-MECH-AI-3.md`），
自带异构审查标记为 `flawed`。我们复核后**修复了两处硬伤**，得到下面的严格版本。**核心
洞察（连续界在 ε→0 时无法覆盖离散跃迁）是对的，但原始证明有漏洞，不能直接发表。**

**形式化目标**：
```
S_mix(ε) = sup_{||c'-c||≤ε, z'∈N_G(z)} d_Y(f(c',z'), f(c,z))
```

**假设**：
- **A1**（中）：对每个 z'∈N_G(z)，映射 f(·,z') 在 c 的 ε 邻域内是 L_z'-Lipschitz。
- **A2**（强）：图 G 的邻域 N_G(z) 包含本次认证所声明覆盖的所有合法离散 substitution。
- **A3**（中）：输出距离 d_Y 满足三角不等式，且单位/缺失值语义已规范化。
- **A4**（新增，修复 L_G 偷换）：统一常数 L_G = sup_{z'∈N_G(z)} L_z' 存在且有限。

**修正后的 D_G 定义**（修复"漏对 c' 取 sup"）：
```
D_G(ε) = sup_{||c'-c||≤ε} max_{z'∈N_G(z)} d_Y(f(c',z'), f(c,z))
```
（原始版本写成 D_G = max_{z'∈N_G(z)} d_Y(f(c,z'),f(c,z))，漏掉了对 c' 取 sup——因为
D_G 依赖 c，当 c' 在 ε 邻域内变化时 D_G 可能不同。修正后显式对 c' 取 sup。）

**推导**：
1. d_Y(f(c',z'),f(c,z)) ≤ d_Y(f(c',z'),f(c,z')) + d_Y(f(c,z'),f(c,z))  ‖ 三角不等式 (A3)
2. d_Y(f(c',z'),f(c,z)) ≤ L_z'·||c'-c|| + d_Y(f(c,z'),f(c,z))  ‖ A1
3. d_Y(f(c',z'),f(c,z)) ≤ L_G·||c'-c|| + D_G(c)  ‖ A4 及 D_G 定义
4. S_mix(ε) ≤ L_G·ε + D_G(ε)  ‖ 对 c' 取 sup（修正后）
5. S_mix(0) = max_{z'∈N_G(z)} d_Y(f(c,z'),f(c,z)) = D_G(0)  ‖ ε=0 时 c'=c
6. **D_G(0)>0 ⟹ S_mix(0)=D_G(0)>0=L·0**  ‖ 连续界在零连续半径处无法覆盖非零离散跃迁
7. S_mix(ε) ≤ L_G·ε + D_G(ε)，且 S_mix(0)=D_G(0)  ‖ 合并

**核心命题（理论底座）**：
> 若存在 z'∈N_G(z) 使 d_Y(f(c,z'),f(c,z)) > 0，则 S_mix(0) = D_G(0) > 0 = L·0。
> 即**纯连续界在 ε→0 时无法覆盖该离散跃迁**；混合界 S_mix 显式计入 D_G(0)。

**单调性**：扩大 N_G(z) 则 D_G(ε) 与 S_mix(ε) 均不减（集合取 sup 的单调性）。

**渐近**：ε→0 时 S_mix(ε) 的上界趋于 D_G(0) 而非 0；若 D_G(0)>0，纯连续局部化无法消除
该风险。

**可证伪预测**：存在 D_G(0)>0 的离散邻边时，纯连续界必然低估至少某些离散 substitution
的局部 worst-case 风险。**注意：90%/60%/90%/2倍这些经验百分比不能由理论推出**，只能由
实验校准。

**修复说明（相对原始 AI 推导）**：
- 原始第 3 步从逐点 L_z' 偷换成统一 L_G，未声明有限性 → **加 A4 修复**。
- 原始 D_G 定义漏了对 c' 取 sup（D_G 依赖 c）→ **改为 D_G(ε) 修复**。
- 原始 A2 与"枚举或抽样"矛盾 → **明确 A2 要求枚举覆盖，抽样只能给部分覆盖**。

### 2.3 诚实的方法定位
修复后的理论是**条件性的、结构性的**，不是深刻的数学定理——它用现成的三角不等式 +
Lipschitz，把"连续界漏离散"这个现象变成**严格的、可验证的表述**。它的价值在于给论文
一个"为什么"的严格基础，但**别吹成重大数学创新**。论文的卖点是：**理论给"为什么"
（S_mix(0)=D_G>0），实证给"确实如此"（输出跳 66%、AI 会犯、决策会翻、tau 预测、
筛查器解决）**。

### 2.4 边际模型：决策翻转的充要条件

**动机**：核心命题（2.2）认证的是**输出**跳变 D_G。但输出跳变**不能**预测决策翻转
（4 宇宙 48 格 corr +0.11）。所以需要第二个理论，解释**什么决定决策是否翻转**。

我们先提的是 tau 假设（排名相关预测翻转，corr −0.89），但那只是**相关**。扩到 4 个
symbol 宇宙后发现它可以被**推导**出来。

**推导**：设 $q_s$ 为基准参数下的取值、$f_s$ 为离散邻居下的取值，
$r_s = f_s/q_s$ 为该替换对每个标的施加的**缩放**。对有序对 $(a,b)$，$q_a > q_b$：

$$f_a > f_b \iff r_a q_a > r_b q_b \iff \log r_a - \log r_b > -(\log q_a - \log q_b)$$

记 $U = \Delta\log q$（**标的间距**）、$V = \Delta\log r$（**差异化缩放**），则该对
**翻转当且仅当 $|V| > |U|$ 且方向相反**：

> **离散替换翻转一个决策，当且仅当它的「差异化效应」超过「决策边际」。**

**跳变的绝对大小根本不出现在条件里**——只有它的离散度相对于标的间距。这就是"连续界
测错了量"的精确含义：它测的是输出空间的 $|\Delta|$，而翻转条件里压根没有绝对幅度。

若 $U \sim N(0, 2\sigma_q^2)$、$V \sim N(0, 2\sigma_r^2)$ 独立，则
$P(|V|>|U|) = \frac{2}{\pi}\arctan(\sigma_r/\sigma_q)$，于是令
$\boxed{\rho = \sigma_r/\sigma_q}$：

$$\text{两两翻转率} = \tfrac{1}{\pi}\arctan(\rho), \qquad \tau = 1 - \tfrac{2}{\pi}\arctan(\rho)$$

**tau 和翻转率是同一个量 ρ 的两个投影。** 这就解释了 tau 为什么能预测到 −0.89——
那是恒等式加噪声，不是经验巧合。

**实证（48 格，M1–M4 全 PASS，见 3.9）**：恒等式 M1 误差 0.0000；闭式解 M2 的 MAE
3.16pp、corr(预测,实测) +0.877；M3 中 corr(ρ, flip)=**+0.851** 对比
corr(jump, flip)=**+0.110**。

### 2.4b 决策几何：ρ 与 S_mix 不是先后修正，是各管一半

上面那句"绝对幅度不出现在条件里"**只对序关系决策成立**，不能推广。

考虑**绝对阈值决策**：「这家公司营收超过 100 亿没有？」。翻转取决于替换有没有把标的
推过一个**固定常数**，而那取决于**共同缩放**。绝对幅度在这里恰恰是对的量，而 ρ 是
尺度无关的，对它必然失明。

把对数缩放分解：$\log r = \mu_r + \text{偏差}$

- $\mu_r = \text{mean}(\log r)$：每个标的都受到的**共同缩放**——这正是输出跳变测的量。
- $\sigma_r = \text{stdev}(\log r)$：**差异化**缩放。

于是（$\sigma_q$ 为标的间距）：

| 决策族 | 支配量 | 原因 |
|---|---|---|
| 序关系（top-k、两两、排名中位） | $\rho = \sigma_r/\sigma_q$ | 共同缩放在比较中抵消 |
| 绝对阈值（> T） | $\kappa = \lvert\mu_r\rvert/\sigma_q$ | 共同缩放就是全部效应 |

**交叉已验证（48 格，C1–C4 全 PASS，见 3.11）**：

| 预测量 | 序关系决策 | 绝对阈值决策 |
|---|---|---|
| $\rho = \sigma_r/\sigma_q$ | **+0.791** | +0.377 |
| $\kappa = \lvert\mu_r\rvert/\sigma_q$ | **−0.028** | **+0.908** |
| 输出跳变（≈ $D_G$） | −0.050 | **+0.861** |

$\kappa$ 在序关系决策上**基本正好是零**（−0.028）。这不是"预测力弱"，**这正是正确的
预测**：共同缩放不可能重排任何东西，所以测量它的量必须对重排毫无信号。

**这改变了论文骨架**。$S_{mix}$ 不再是被我们自己取代的中间产物：

| | 序关系决策 | 绝对阈值决策 |
|---|---|---|
| 连续 Lipschitz 界（L·ε） | **0 —— 虚假安全感** | **0 —— 虚假安全感** |
| 混合界 $S_{mix}$ / $D_G$ | 测错了量（−0.05） | **对（+0.86）** |
| 边际比 $\rho$ | **对（+0.79）** | 测错了量（+0.38） |

**连续界对两族都错**（离散替换 ε=0，无论 agent 在做哪种决策它都报零），而另外两个量
各自恰好对一族。**贡献是知道 agent 需要哪一个，而今天在用的认证两个都不提供。**

**与核心命题的关系（修正后）**：
- 核心命题（2.2）：连续界漏输出跳变 → 混合界 $S_{mix}$ 覆盖 → **对阈值决策正确**。
- 边际模型（2.4）：序关系决策由 $\rho$ 支配 → **对序关系决策正确**。
- 两者**不是因果链，是按决策几何切分的互补两腿**。

**（注：以上"绝对幅度不出现"仅对序关系决策成立，阈值决策见 2.4b。）**

**tau 降级为推论**：tau 不再是独立发现，而是 $\tau = 1 - 2\cdot\text{flip}$ 的换写。
论文里 tau 是"可从 ρ 导出的可观测量"，不是第二个理论。

**可操作价值**：ρ 比枚举便宜（算两个标准差 vs 重查所有邻居），且**逐查询可算**——
σ_q 是 agent 当前在比较的那组标的的属性。代价是 ρ 没有"每个工具一个值"，它依赖查询。

**已被证伪的解释（诚实记录）**：我们曾预测 tau 由**季节性离散度**驱动（fy 是四个季度
之和，各公司季节形状不同 → tau 低）。这被 P2 证伪，且是**反方向**证伪：CONSUMER 宇宙
的 tau 反而更高（0.799 vs 0.612）。真实原因是该宇宙标的间距极大（WMT 营收约 6800 亿
vs WING 约 6 亿，差三个数量级），任何替换都无法重排。**季节性解释不得写进论文。**

### 2.5 理论逻辑总览（三层）

**起点（现象）**：AI 调工具翻错离散参数（period=quarter→fy），输出跳 66–72%，但现有
连续认证说"零误差"——虚假安全感。

**第一层（核心命题，理论）**：S_mix(0) = D_G(0) > 0 = L·0。连续界在 ε→0 时给 0（只认
连续小动），但离散替换的 worst-case 跳变 D_G(0)>0，所以连续界**必然**漏掉离散跃迁。
→ 回答"为什么现有认证会骗人"。

**第二层（决策几何，可推导的机制）**：跳变会不会到达决策，取决于**决策的几何形状**。
序关系决策（top-k/两两）由 $\rho=\sigma_r/\sigma_q$ 支配——条件是
$|\Delta\log r|>|\Delta\log q|$，绝对幅度不出现（corr +0.791，而输出跳变仅 −0.050）；
绝对阈值决策由 $\kappa=|\mu_r|/\sigma_q$ 支配——共同缩放就是全部效应（corr +0.908，
输出跳变 +0.861 也对）。**连续界对两族都报零。** tau 是序关系那支的推论
$\tau=1-2\cdot\text{flip}$。→ 回答"输出跳了，决策会不会翻，以及该看哪个量"。

**第三层（筛查器，工具）**：枚举筛查器决策前枚举离散邻居、重算决策、看是否翻转，把
决策错误从 12% 降到 0%；tau 给更便宜的信号（算 tau 而非枚举）。→ 回答"怎么兜底"。

**三层关系**：连续界漏输出跳变（S_mix 理论）→ 输出跳变是否翻决策由 tau 决定（tau
理论）→ 用筛查器兜底（实证）。

**上游机制层（2.7）**：三层之上是机制层——为什么 LLM 会填错离散参数。绑定信号 $d$
被符号偏好 $a$ 压过（阶段 A，3.13）。机制层给三层一个"为什么"：不是不懂语义，而是
绑定不支配。完整因果链：**为什么填错（绑定不支配）→ 填错会怎样（决策翻转）→ 为什么
没人防住（认证缺口）**。

**硬度分层（诚实）**：第一层是修复后的理论（条件性成立，需 A1-A4）；第二层**从实证
规律升级为推导**——翻转条件是恒等式（精确），arctan 速率是高斯近似（MAE 3.16pp），
在 4 宇宙 48 格上验证，但仍是单 API、单离散参数、全美股，且 16/48 格因取对数丢弃了
非正值标的；第三层是工具（端到端模拟，非真实 agent）。

### 2.7 机制层：为什么 LLM 会填错离散参数（语义绑定）

上面三层回答"离散错误一旦发生会怎样、现有认证为什么漏、怎么兜底"。它们把
"LLM 填错参数"当作**既成事实**（B2）。本节回答它的**上游**：为什么 LLM 会生成
schema-valid 但语义错误的参数？这是老师要求的"现象背后的原理"。

**核心假设**：任务语义可以被模型表示，但它与工具参数的**绑定**未必充分控制实际
生成；**非绑定的输出偏好可能压过正确绑定信号**。完整推导见
`docs/llm_semantic_binding_theory.md`，这里给结论。

**形式化**（饱和二因子/Walsh 展开，恒等式，非新数学）：
- $u\in\{-1,+1\}$ 请求语义（季度/全年），$z\in\{-1,+1\}$ 输出符号，
  $v\in\{-1,+1\}$ schema 映射方向；正确参数 $z^*=uv$。
- 输出对数优势 $\ell(u,v)=\log\frac{P(a_+\mid I_u,S_v)}{P(a_-\mid I_u,S_v)}$
  可唯一展开为 $\ell = a + bu + cv + duv$：
  - $a$ 固定符号偏好，$b$ 请求主效应，$c$ schema 主效应，$d$ 方向正确的请求×映射交互。

**命题 1**：四种请求—映射组合全部正确 ⟺ $d > B$，其中
$B=\max_{u,v}\{-a uv-bv-cu\}$（保守充分条件 $d>|a|+|b|+|c|$）。

**承重反例**：$a=2,b=c=0,d=1$ → $\ell=2+uv>0$ 恒成立，模型永远选 A，四种平衡组合
错两种。**"存在正确方向的交互项" ≠ "实际参数正确"**——这正是"为什么填错"的机制
答案：绑定信号 $d$ 存在，但被符号偏好 $a$ 压过。

**合法性 ≠ 正确性**：$\hat z\in\mathcal Z_{valid}$（schema 合法）不推出
$\hat z=uv$（任务正确）。前者约束集合成员资格，后者约束请求、schema、输出的关系。

**与三层的关系**：机制层（本节）是后果层（2.2–2.5）的**上游**。它解释"为什么会有
离散错误"；后果层解释"这个错误一旦发生会怎样"。两者合成完整因果链：
**为什么填错（绑定不支配）→ 填错会怎样（决策翻转）→ 为什么没人防住（认证缺口）**。

**诚实边界**：本节是**行为层**的绑定假设，不定位内部神经机制（那是阶段 C 激活干预）。
$d>B$ 是恒等式不是发现；$d$ 是行为上的绑定一致性交互，不自动对应某个内部模块。

## 3. 实验与结果（完整证据链）

### 3.1 Phase-0：离散跃迁存在（$0，8 symbol，96 替换）
findata 离散参数产生连续界覆盖不到的输出跃迁：
- **D1 PASS**：离散跃迁存在，62.5%（60/96 rel_diff > 10%）
- **D2 PASS**：连续界覆盖不到（结构性，ε=0）
- **D3 PASS**：schema-valid 100%（96/96，替换是合法调用，不是 malformed）
- 例子：period=quarter→fy，eps 2.04→6.11（66.6%）、revenue 109B→391B（72%）

### 3.2 generator relevance：真实 LLM 会犯这些错误（跨模型）
验证离散错误不是纯结构，真实生成器会犯：
- **deepseek-v4-flash（强）**：60% 离散错误，**0 高影响**（period=fy）
- **gemma3:12b（强，本地）**：0% 离散错误
- **llama3.1:8b（弱，本地）**：50% 离散错误，**2 高影响（12%）**
- **qwen2.5:7b（弱，本地）**：50% 离散错误，**3 高影响（18.75%）**

**关键发现**：错误率跟模型对工具调用的遵循能力有关。强模型（deepseek/gemma3）遵循好，
不犯高影响错误；弱模型（llama3.1/qwen2.5，成本低、真实部署更常用）犯高影响离散错误
（period=fy，12–18.75%），连续界漏掉它们——这是卡片 3 的价值。

### 3.3 混合敏感度：连续界漏、混合界盖（8 symbol，全 PASS）
对比连续界（L·ε）、混合界（S_mix）、经验值：
- **M1 PASS**：连续界（ε=0）=0，漏掉 50% 的跃迁（quarter→fy 的 37–72%）
- **M2 PASS**：混合界 S_mix=D_G，覆盖所有跃迁
- **M3 PASS**：D_G 有界（max 72%），有筛查价值
- 例子：AAPL period=quarter→fy D_G=72%（eps 2.04→6.11），连续界=0 漏掉，S_mix=72% 覆盖

### 3.4 扩大 + 消融：增量是结构性的（20 symbol，420 跃迁，全 PASS）
覆盖 4 端点（fundamentals/enterprise-value/key-metrics/owner-earnings）、2 离散参数
（period/statement）、20 symbol：
- **S1 PASS**：增量跨端点成立（enterprise-value 86.7%、fundamentals 97.3%、key-metrics 53.1%）
- **S2 PASS**：增量跨参数成立（period quarter→fy 97.3%、statement income→balance/cashflow 100%）
- **S3 PASS**：增量跨 symbol 成立（20/20 个 symbol 的 D_G > 10%，37.5%~97.3%）
- **消融定位增量来源**：增量是结构性的，来自离散参数本身——
  ① period 替换（quarter→fy）= **数值跃迁**（eps 2.04→6.11，97%）
  ② statement 替换（income→balance/cashflow）= **结构跃迁**（income 的 eps 在 balance 里不存在，100%）
  ③ 跨端点/字段/symbol 都成立，不依赖特定 symbol/端点/字段/参数

**结论**：period 替换=数值跃迁，statement 替换=结构跃迁，两者都是连续界（ε=0）覆盖
不到的离散跃迁。增量是真正的结构性发现。

### 3.5 端到端：筛查器能否解决问题（Monte Carlo，50k runs）
"发现问题"之后是"解决问题"：筛查器能否**降低最终做错决策的比例**。诚实定位——筛查器
**不是让模型少犯错**（弱模型 12–18.75% 的错误率改不了），而是**在模型犯错时拦住错误
结果**。决策任务"按 EPS 排名选最贵 3 个"，correct=quarter，agent 以概率 p 翻成 fy：
- **裸跑组**：翻错就直接用错数据做决策。
- **筛查组**：决策前跑筛查器，标记"危险"则重查正确参数。

| p_err | 裸跑 | 输出跳变筛查 | 枚举筛查 | 输出跳变 re-query | 枚举 re-query |
|---|---|---|---|---|---|
| 12.0% | 12.1% | 3.8% | **0.0%** | 11.5% | 12.1% |
| 18.8% | 19.0% | 5.9% | **0.0%** | 18.0% | 19.0% |

**关键结果**：
- **输出跳变筛查只降 ~69%**（12%→3.8%）——它漏 31% 的决策翻转，正是变体 A 的 D4
  失败，现在证明它有真实的端到端代价。
- **枚举筛查降到 0%**（12%→0%），代价是每次重查（12.1% re-query = 安全的价格）。
- 在实测弱模型错误率（12–18.75%）下，枚举筛查把决策错误从 ~12% 降到 **0%**。

**这是"解决问题"的证据**：不是让 agent 更聪明，而是在错误到达决策前拦住它。枚举筛查
是可落地的工具，输出跳变筛查是不完整的 baseline（正好当 motivation）。

### 3.6 多决策泛化：决策翻转是普遍的，且暴露结构（20 symbol，4 字段）
变体 A 只测了一个决策（EPS 排名选 top-3）。这个探针在**同一数据**上测多种决策
（top-3 昂贵/便宜、中位数阈值、两两比较），看决策翻转是否普遍：
- **10/12 个决策任务翻转 >20% → 决策翻转是普遍的**，不是 EPS 排名特有的。
- **但翻转率不均匀，这暴露了结构**：
  - **eps / net_income**：几乎全翻（80%）——跳得狠且相对排名变。
  - **revenue**：top-3 昂贵**完全不翻**（overlap 100%）——大公司全年 revenue ≈ 4×季度，
    排名几乎不变。
  - **operating_income**：中等。
- **理论种子**：决策翻转取决于离散替换是否改变**相对排名**，不只是跳变幅度。字段可以
  跳 66%（revenue）却保住 top-3（所有 symbol 同向缩放），也可以跳得少却翻转（相对顺序
  变）。这推广了变体 A 的 D4 发现（输出跳变不预测决策翻转）。

### 3.7 tau 假设验证：排名相关预测决策翻转（corr −0.98）
> **已被 3.8–3.10 取代。** 保留作为时间线记录：tau 最初是 n=4 的相关，现已被 3.10 推导
> 为 ρ 的推论。论文正文用 3.10 的表述，不用本节的 −0.98。
把理论种子变成可检验的预测：**决策翻转率由两个 period 的排名相关（Kendall tau）决定**。
- | 字段 | tau | 翻转率 |
  |---|---|---|
  | eps | +0.421 | 59.7% |
  | net_income | +0.568 | 54.5% |
  | operating_income | +0.737 | 35.8% |
  | revenue | +0.853 | 23.4% |
- **corr(tau, flip_rate) = −0.98 → CONFIRMED**。近乎完美的单调关系：tau 高（排名稳）→
  翻转低；tau 低（排名重排）→ 翻转高。
- **这升级了故事**：变体 A 的 D4 是负结果（输出跳变不预测决策翻转，corr −0.12）；tau 是
  正结果（排名相关预测决策翻转，corr −0.98）。给筛查器一个**更便宜的信号**——不用枚举
  所有邻居（贵），算 tau（便宜），tau 低就知道决策会翻。
- **理论主张（可检验）**：决策翻转率 ≈ 单调递减于离散邻居间的排名相关 tau。连续界认证
  输出稳定性（L·ε），但决策安全由排名稳定性（tau）决定，而连续界不测 tau。混合界覆盖
  输出跳变 D_G，tau 决定这个跳变是否到达决策。
- **局限**：n=4 字段太小，−0.98 是 suggestive 不是 powered。→ 由 3.8 扩样本解决。

### 3.8 tau 扩样本：12 字段 × 20 symbol，五项稳健性全过
n=4 无法区分"机制"与"巧合"。扩到该 API 所有带 quarter/fy 的字段：**12 字段 × 20
symbol × 3 端点 = 240 观测**（$0，无模型——tau 是数据属性不是模型行为）。H1–H5 的预测
连同"每种失败该怎么改口径"在跑之前就写死在 `tau_expand.py` 里。

| 检验 | 统计量 | 结论 |
|---|---|---|
| H1 corr(tau, flip)，n=12 | **−0.890** | PASS |
| H2 组内：fundamentals(6) / enterprise-value(4) | −0.894 / −0.987 | PASS |
| H2 组内：flow(7) / stock(5) | −0.896 / −0.950 | PASS |
| H3 Spearman(tau, flip) | −0.845 | PASS |
| H4 偏相关 corr(tau, flip \| jump) | **−0.881** | PASS |
| H5 置换检验（20k 次） | p = 0.0001 | PASS |

- 相关从 −0.98（n=4）衰减到 **−0.890**（n=12）。这正是一个小样本估计在诚实扩样本后
  该有的表现——它衰减了，但没有崩。
- **H2 是承重的一条**。最显然的混淆是：tau 也许只是在区分**字段族**——流量字段
  （revenue/eps，按期累计）vs 存量字段（market_cap/total_debt，时点快照）。若如此，
  族内相关应当消失。它没有：flow 组内 −0.896，stock 组内 −0.950，单端点内 −0.894。
  **tau 在族内也能排序字段，不只是在族间划线。**
- **H4 排除了廉价解释**。tau 与输出跳变只有 r=−0.313 的弱关系；控制 jump 后 tau 与
  翻转的关系几乎不动（−0.890 → −0.881）。**tau 不是输出跳变的换皮。**
- **不用统计就能讲清论点的对比样例**：
  - `revenue`：输出跳 **63.5%**，决策只翻 **24.7%**
  - `current_ratio`：输出只跳 **9.9%**，决策却翻 **32.8%**

  数值动了三分之二的字段，比几乎没动的字段翻转更少。**输出幅度是错的观察量，排名
  稳定性才是对的。**
- **~~必须修正 D4 的口径~~（本条已被 3.10 推翻）**：这里测得字段层面
  corr(jump,flip)=+0.432，我们据此认为不能再说"输出跳变不预测决策翻转"。3.10 在 4 个
  宇宙 48 格上重测得 **+0.11**——**+0.432 是单宇宙假象**。最终口径见 3.10。
- **剩余局限**：12 字段是该 API 的上限（key-metrics 的 pe/pb/ps/roe 等直接返回 `None`，
  owner-earnings 的 fy 返回空数组，statement 的邻居字段集不相交因而无共同排名）；单
  API、单离散参数、单 symbol 宇宙（20 只美股大盘科技股）；12 个字段彼此不独立
  （revenue/gross_profit/operating_income/ebitda 是嵌套会计口径），有效 n 小于 12，
  p=0.0001 偏乐观。→ 由 3.9 换宇宙解决。

### 3.11 决策几何交叉：ρ 与 D_G 各管一半（C1–C4 全 PASS）
3.10 读起来像是"$D_G$ 被我们自己的结果废掉了"。这个探针检验一个更准确的说法：
**对的量取决于决策的几何形状**。同一批 48 格，零新增取数。

分解 $\log r = \mu_r + \text{偏差}$：$\mu_r$ 是共同缩放（输出跳变测的就是它），
$\sigma_r$ 是差异化缩放。预测：序关系决策由 $\rho=\sigma_r/\sigma_q$ 支配（共同缩放
在比较中抵消），绝对阈值决策由 $\kappa=|\mu_r|/\sigma_q$ 支配（共同缩放就是全部）。

| 预测量 | 序关系决策 | 绝对阈值决策 |
|---|---|---|
| $\rho$ | **+0.791** | +0.377 |
| $\kappa$ | **−0.028** | **+0.908** |
| 输出跳变（≈$D_G$） | −0.050 | **+0.861** |

- **C4 可分性**：corr(ρ, κ)=+0.169，两者不共线，交叉检验有效。
- **C1/C2/C3 全 PASS**，Spearman 一致（ρ: +0.837/+0.385；κ: +0.026/+0.917），
  组内中心化后依然成立（ρ→序 +0.755，κ→阈值 +0.922，κ→序 +0.038）。
- **$\kappa$ 在序关系决策上基本正好是零（−0.028）**——这不是预测力弱，**这正是正确
  的预测**：共同缩放不可能重排任何东西。
- **对论文的意义**：$S_{mix}$ 救活了。它是**阈值决策**的正确工具（+0.861），ρ 是
  **序关系决策**的正确工具（+0.791），而连续界对**两族都报零**。核心表格见 2.4b。

**阈值设定的说明（诚实）**：T 取基准（quarter）分布的 25/50/75 分位，选定后在替换过程中
固定不变。它们确实是常数（这是要点），但是从标的集**标定**出来的，不是来自真实 agent
的规则手册。像"营收 > 100 亿"这种落在标的范围之外的规则会给出接近 0 的翻转率、不带
信号；我们的阈值落在决策真正活跃的区间。

### 3.12 把 CertDR 当 baseline 跑：共模扰动下 union bound 近乎空洞（B1–B4 全 PASS）
同一批 48 格，K=3，**per-item 预算取精确偏差**（对 baseline 最慷慨的实例化——真实
CertDR 用的是同义词重叠推出的上界，忠实移植只会认证得更少）。

| | 认证数 | 占 14 个真实稳定格 |
|---|---|---|
| CertDR 判据（原样，在位者豁免） | 1/48 | — |
| union bound（修好在位者移动，sound） | **2/48 (4.2%)** | 2/14 (14.3%) |
| 同一界作用在共模商上 | 3/48 (6.2%) | 3/14 (21.4%) |
| **实际** | 34/48 翻转，**14 格稳定** | |

- **B1 PASS**：sound union bound 只认证 4.2%。
- **B2 PASS（最强的一条）**：**这不是因为决策脆弱**——14 个格子真的稳定，它只证出 2 个。
  它在另外 12 个上失败不是因为它们会翻（不翻），而是因为**逐项独立收全额预算**，而移动
  大部分是共模。中位 $o_{quot}/o_{union}=0.518$：**约一半预算花在无法重排任何东西的
  共同缩放上。**
- **B3 PASS 但只多救回 1 格**（2→3）。**不许抛光**。诚实结论：**最坏情况界在这里怎么修
  都是错工具**——相关扰动的最坏情况被**单个**最被重标定的标的支配，一个就够毁掉界，
  哪怕排名纹丝不动。所以正确对象是**速率**（ρ，corr +0.851），不是界。
- **B4 PASS**：共模商化严格保序因而 sound，零假认证。
- **B0 的精确表述**：CertDR 判据豁免在位者，保证**不迁移**；但本数据零假认证（它本来就
  几乎不认证）。**报成假设错配，不得报成实证证伪。**

### 3.13 语义绑定：绑定不支配、符号偏好压过（阶段 A，qwen2.5:7b-instruct）

验证 2.7 的机制层命题。50 个任务单元（10 任务 × 原生 + 适配），每个单元构造完整
u×v 四格，用 transformers 拿参数位置的精确 logits，恢复 a,b,c,d，判 $d>B$。
脚本 `probes/stageA_binding.py`，数据 `stageA_binding.jsonl`。

**原生接口（请求理解，b 主效应）**：10/10 任务 `b>0`——模型能正确读出"季度 vs 全年"。
**请求理解不是失败点。**

**适配接口（绑定，完整 a,b,c,d），40 单元**：

| 判定 | 数量 | 占比 |
|---|---|---|
| V1: $d>B$（绑定支配） | 4/40 | 10% |
| V2: $d>0$ 但参数仍错（正交互被压过） | 24/40 | 60% |
| V3: 符号偏好 $\lvert a\rvert>0.5$ | 37/40 | 92% |

**关键发现**：
- **绑定几乎从不支配**（V1 10%）。4/40 全在中性任务的 Q-A 符号对，金融任务一个都没有。
- **符号偏好压倒性**（V3 92%）。金融任务 $\lvert a\rvert$ 高达 5.5–9.9——非常强的固定
  符号偏好，直接支持"非绑定输出偏好压过正确绑定信号"。
- **"正交互但参数仍错"大量存在**（V2 60%）。24/40 单元 $d>0$ 但 $d\le B$——正是
  2.7 反例（$a=2,b=c=0,d=1$）的现实版：模型有正确方向的绑定信号，但被压过。
- **金融 vs 中性**：金融任务符号偏好强（a≈6–9）、绑定几乎不支配；中性任务偏好较弱、
  偶有绑定支配（Q-A 对）。

**已知 confound（记录，不重跑）**：$\lvert a\rvert$ 偏大，可能混入"模型在参数位置不情愿
输出裸符号"的位置效应。这不改变主线结论（绑定不支配、符号偏好压过），故不为此反复
重跑；在 Limitations 里如实记录。

**与三层的关系**：阶段 A 给 B2 的"LLM 填错参数"提供了机制解释——不是不懂语义
（原生 b>0 全过），而是**绑定信号被符号偏好压过**。这把"为什么填错"从既成事实
升级为有原理支撑的机制。

### 3.14 激活干预：绑定信号定位在晚期层（阶段 C，qwen2.5:7b-instruct）

阶段 A 是行为层。阶段 C 用激活替换（causal tracing）检验**是否存在某层激活按
uv 关系控制参数选择**——机制层的因果证据。对 fin_aapl_rev 的 4 个 u×v 输入记录
每层激活，把源输入的激活 patch 进目标输入，测参数偏好 ell 的变化。脚本
`probes/stageC_patch.py`，数据 `stageC_patch.jsonl`。

**绑定信号定位在晚期层**：

| 层 | mean \|delta ell\| | 解读 |
|---|---|---|
| 0–16 | < 0.33 | 早期层不承载 u/v 区分信号 |
| 17–18 | 0.65–1.03 | 起始 |
| 19–25 | 5.27–10.04 | 晚期层强烈改变参数偏好 |

**real patch 超过 random 对照**（等强度随机向量，晚期层）：

| target | 层 | real delta | random delta |
|---|---|---|---|
| u=-1,v=-1 | L19 | −5.56 | −3.94 |
| | L20 | −6.69 | −3.31 |
| | L21 | −7.88 | −2.31 |
| u=+1,v=+1 | L19 | −14.56 | −7.62 |
| | L20 | −17.75 | −7.06 |
| | L21 | −18.44 | −6.44 |

**关键发现**：晚期层（19–25）的激活替换显著改变参数偏好，且 **real patch 超过
random 对照 2–3 倍**（如 L20: −17.75 vs −7.06）。这说明晚期层**确实承载绑定信号**，
不只是普遍破坏——替换真实激活比替换等强度随机向量产生大得多的效应。绑定信号
定位在接近输出端的晚期层，符合"早期层处理通用语义、晚期层把 u/v 绑定到参数选择"
的直觉。

**与机制层的关系**：阶段 C 给阶段 A 的行为结果提供了因果方向的证据——晚期层激活
确实按 uv 关系影响参数选择（real > random）。机制层从"行为上绑定不支配"升级为
"存在承载绑定信号的层"。

### 3.15 真实 agent 端到端：真实错误率 + 筛查器拦截（阶段 D，qwen2.5:7b）

论文此前最关键的缺口：端到端是 Monte Carlo 模拟（假设错误率 p），没有真实 agent。
阶段 D 用真实 LLM agent（qwen2.5:7b）替代模拟。脚本 `probes/agent_end_to_end.py`，
数据 `agent_end_to_end.jsonl`。

**D1 — 真实错误率（40%）**：真实 agent 在模糊问题上 100% 填 `period="all"`（规避
quarter/fy 选择），明确问题 0 错误。20/50 参数错误。**这支持机制层**——绑定在模糊
输入上不充分，agent 不把"季度/全年"绑定到明确的 period 值，退回 all。

**D3 — 筛查器拦截（30% → 0%）**：模拟 agent 互翻 period（quarter↔fy，真正产生决策
错误的模式），baseline 决策错误 30%，**筛查器把它降到 0%**。筛查器检测参数错误并
重查正确 period。

| 指标 | 值 |
|---|---|
| D1 真实错误率 | 40%（模糊问题 100% 填 all） |
| D3 baseline 决策错误 | 30% |
| D3 screener 决策错误 | **0%** |

**完整链条成立**：
- 真实 agent 填错参数（D1，填 all）→ **机制层**
- 填错方向时决策翻转（D3 baseline 30%）→ **后果层**
- 筛查器拦截（D3 screener 0%）→ **筛查器价值**

**设计修正（诚实记录）**：初版设计让 all 返回与 quarter 相同的数据，决策本就不错，
筛查器无价值可展示——那是设计缺陷，不是负结果。修正后模拟互翻（真正产生决策错误
的模式），筛查器价值可见：30% → 0%。

### 4.1 三条谱系，我们站在交叉处

**谱系 A — 连续认证机器（我们继承它的工具，批评它的移植）**
Lipschitz/ℓp 那套机器出自 $\mathbb{R}^d$ 上的注意力分析（Kim et al. ICML 2021；
Castin et al. ICML 2024 ○）。**注意**：这条线本身没错，错的是移植方式。

**谱系 B — 离散替换认证（成熟，我们必须当作已知前提引用）**
三代俱全：IBP（Jia et al. 1909.00986 ✅ 定义读过；Huang et al. 1909.01492 ○）、
随机平滑（SAFER 2005.14424 ○）、分区/枚举聚合（erase-and-check 2309.02705 ○、
RobustRAG 2405.15556 ○）。**"枚举离散邻域"2019 年就是标准做法**，且被明确当作
不可扩展的 oracle（Jia 算过单样本 $10^{31}$ 种扰动）。

**谱系 C — agent 侧认证（最近，且刻意避开连续几何）**
LLMCert-T（2510.03992 ○）认证**工具选择**，用 Clopper–Pearson 而非范数球；
role-stratified conformal risk control（2607.24343 ○）按**后果严重性**分层。
经验基准：ToolRobustBench（2608.23635 ○，`argument binding` 是其失败归因轴之一）、
2506.21967 ○（把"参数生成"列为高脆弱阶段）。

**交叉处是空的**：**已选定工具的参数取值**这一层，连续证书和离散证书**都不存在**。
现象被反复测到（谱系 C 的基准），但没人去证。

### 4.2 直接 baseline：CertDR，以及它为什么在我们的场景里失效 ✅

CertDR（2209.06691, CIKM 2022）是离我们最近的一篇：离散替换下的**排序**证书，
判据是**边际形式**。我读了它的定义原文：

| CertDR 方法节原文 | 含义 |
|---|---|
| Def 3.1 `S_d := {d' : ‖d'−d‖₀/‖d‖ ≤ δ}` | 邻域按**单个文档**索引，只由该文档自己的词构成 |
| Def 3.2 `∀d ∈ L_q[K+1:], ∀d' ∈ S_d` | 对每个文档**分别**成立 |
| Thm 4.1 逐文档独立应用，$o_d$ 是 per-document | 偏差界逐项算 |
| Prop 4.2 `gap(d_K,d_{K+1}) − max_d o_d > 0` | **union bound**：每项各自按最坏方向独立移动 |
| 威胁模型：`documents already ranked 1..K are excluded from attack` | **在位者豁免** |
| §4 原文：`Here, we leave the query q free from attack. In the future work, we would like to explore the defense against query attacks by focusing on q` | **查询端未被扰动，且被它自己列为未来工作** |

**最后一行是这次核实捡到的最大收获。** CertDR 扰动的是**被排序对象**（文档），并**明确
把查询端攻击留作未来工作**。而**查询是共模的天然来源**——改一次查询，所有候选项的分数
同时变。我们的离散参数替换**正是作用在调用端（≙ 查询端）**。

所以我们的定位不是"我们和 CertDR 不同"，而是更强的一句：**我们做的正是 CertDR 自己
标为开放的那一格，而且指出那一格的扰动几何是共模的——这恰好是它的 union bound 失效
的原因。**（实验见 3.12：它只认证 2/48，而 14/48 真实稳定。）

我们的扰动是**一次参数替换同时、相关地移动所有标的（含在位者）**。这不是措辞差异，
是能跑出数字的差异（实验见 3.12）：

- 修好在位者移动后的 sound union bound 只认证 **2/48**，而实际稳定的有 **14/48**；
- 它失败不是因为决策脆弱，而是因为**逐项独立收全额预算**，而移动大部分是共模
  （中位 $o_{quot}/o_{union}=0.518$，约一半预算无法重排任何东西）。

**措辞纪律**：CertDR 的判据豁免在位者，所以它的**保证不迁移**到我们的场景——但本数据上
它**零假认证**（因为它几乎什么都不认证，1/48）。**报成假设错配，不得报成"实证证明它
不 sound"**。同理**绝不写 "we fix CertDR"**：共模商化只多救回 1 格，说明**最坏情况界
在相关扰动下怎么修都是错工具**（最坏情况被单个最被重标定的标的支配）。

### 4.3 我们继承的基座（必须正面引，写成"站在其上"）

| 基座 | 内容 | 我们的差异 |
|---|---|---|
| Generalizability theory（Cronbach et al. 1972；Brennan 2001）○ | relative 决策用 $\sigma^2_\delta$、absolute 决策用 $\sigma^2_\Delta$，差别**正是 facet 主效应** | 它是**随机抽样 facet** 的信度系数；我们是 schema 里**选错一个枚举值**，产出**逐查询**筛查而非设计信度 |
| Relative perturbation theory（Demmel & Veselić 1992；Ipsen 1998；Ren-Cang Li I–IV）○ | 乘性扰动下**相对**间隔决定稳定性 | 它是矩阵特征值的确定性界；我们是一群标的上的**速率** |
| CertDR Prop 4.2 ✅ | 边际形式的排序证书 | 逐项独立 vs **共模相关**（见 4.2） |
| 2506.02257 ✅（读过 §1） | 扰动**数据集**、把 margin 当**要摆脱的假设**、输出集值对冲 | 我们把 margin 当**可计算的预测量**，给闭式速率 |
| **2604.11581 附录 D ✅（2026-09-21 自核）** | **已在 LLM 场景下明写 relative/absolute 区分**（见下） | 它讲**评测设计的标准误**；我们讲**工具调用替换下的逐查询翻转预测** |
| 2507.20150 ✅ | 有限集上连续性平凡成立；不稳定源自**离散动作集上的 argmax** | 我们的决策翻转是其在工具参数场景的下游实例 |

**⚠️ 2.4b 的主张必须进一步收窄（2026-09-21 自核后）。** 我原以为 relative/absolute
只被 G-theory（1972）占住、LLM 场景还空着。**不对。** 2604.11581 附录 D 逐字写着：

> "The D-study formulas above give the **absolute** error variance, appropriate for
> **threshold decisions** ('does this model exceed 80% safety?'). For **relative**
> decisions (**comparing two models or ranking items**), **shared main effects such as
> prompt and judge shift all items equally and cancel**… **Applying the absolute formula
> mechanically will overstate some shared sources and understate object-specific
> interactions.**"

"shared main effects … **shift all items equally and cancel**" 就是我们的 $\mu_r$ 在
序关系决策中抵消，一字不差，且是 LLM 评测场景。

**两个必须执行的后果**：
1. **必须引用 2604.11581 附录 D**，并把 2.4b 写成 "we instantiate"。**不得**声称把这个
   区分引入了 LLM 场景——已经有人做了。
2. **撤回**我此前说的"它拿 absolute 公式分析 Chatbot Arena 是一个混淆实例"——**它自己
   在附录里写明了这个警告**。拿它当"无意识混淆的例子"是不诚实的。

**2.4b 剩下的增量**（窄但真实）：它们给的是**评测设计的方差分解与标准误建议**（定性、
无预测量）；我们给的是**逐查询可算的无量纲判据 ρ** 并**实测其对决策翻转的预测力**
（+0.851 vs 输出跳变 +0.110），场景是**工具调用参数替换**而非评测 facet 抽样。

### 4.4 第一层（2026-09-21 全面重写，全部已自核 ✅）

> **旧版本已作废。** 旧说法是"连续界对离散替换给 ε=0，所以失效"。这个说法**站不住**，
> 理由见下面的 Policy Cliff。新说法更窄、更准、且有逐字原文支撑。

#### 4.4.1 为什么旧说法站不住：The Policy Cliff ✅

**2507.20150**（我已下载全文读过）§6.1 与附录明写：

> "**Any metric on a finite set induces the discrete topology**… any function from a space
> with the discrete topology to any other metric space is **necessarily continuous**."
>
> "the source of policy instability in the LLM setting **does not stem from a formal
> 'discontinuity' of the reward function itself**"
>
> "…not as a failure of continuity on the state space, but as **a consequence of the
> inherent discontinuity of optimization over a discrete action set**"

**在有限/离散空间上，连续性是平凡满足的。** 所以"离散破坏了连续性"这句话在数学上是空的，
而且 Lipschitz 性也同样平凡可满足——**用离散度量时** $d(\text{quarter},\text{fy})=1$，
于是 $L\cdot\varepsilon = L\cdot 1 = $ 最大跃迁 $= D_G$，**这个界是有信息的**。

所以真正的问题**不是连续性，而是度量的选择**：把离散枚举嵌进 $\mathbb{R}^d$ 去量 ε，
替换就没有距离；用离散度量则界立刻变成 $D_G$，而**没有人去算它**。

**Policy Cliff 不是我们的对手，是我们的基座**：它的结论"不稳定来自在离散动作集上做
argmax"，正是我们决策翻转机制的上游陈述。**必须引用，且第一层不得再写"连续性失效"。**

#### 4.4.2 真正的靶子：把参数选择建模成 quantization ✅

**2609.16599**（综述，我已下载全文读过）§2.3 把 LLM 的参数输出写成：

> "The parameter actually in force represents a **delayed, quantized**, and potentially
> dropped version of the LLM's raw output… $\hat\theta(t) = q(\theta(t_k))$, where
> $q(\cdot)$ **decodes discrete token sequences onto the valid parameter set $\Theta$**…
> These phenomena correspond directly to the time delay, packet dropout, and
> **signal quantization**"

外加摘要层的领域共识句：

> "inference latency acts as delay, API failures as packet dropouts, tokenization as
> quantization, and **hallucinations as bounded disturbances**"

**这是比旧那三个候选好得多的靶子**，理由有三：

1. 它是**综述**，代表领域共识，不是某位作者的一次性选择；
2. 它扰动的对象**就是我们的对象**——`θ ∈ Θ`，文中列举包括 constraints、triggering
   thresholds、**mode indices**（正是枚举型参数）；
3. **quantization 是一个有界小误差模型**：误差 ≤ 半个步长，且它**预设离散网格是某个
   连续量的细分近似**。

**而枚举参数不是细网格。** `quarter` 与 `fy` 不是同一个连续量上相邻的两格，是**语义上
不同的两个选项**；把一个换成另一个，输出动 **66–72%**，不是半个步长。

> **第一层的正确表述**：领域把离散工具/控制参数的选择建模为 **quantization**（有界、
> 小、可被 disturbance rejection 吸收）。这个误差模型对**语义枚举**不成立——替换不是
> 舍入，而是跳到另一个语义分支。

这个说法**不与 Policy Cliff 冲突**（我们不再声称连续性失效），**不与 LipsLev 冲突**
（我们不再声称 Lipschitz 预设连续），且有逐字原文支撑。

#### 4.4.3 两个次级实例（一个已自核，一个仍未核）

- **2601.18753（ICLR 2026）✅ 已自核**：假设 A2 写
  $\|\Phi(y)-\Phi(y')\| \le L_\Phi d_Y(y,y')$（$d_Y$ 为编辑距离），A3 的扰动球却在
  $B_\rho := \{\delta\in\mathbb{R}^r : \|\delta\|_2\le\rho\}$。**$L_\Phi$ 除 A2 与记号
  回顾外全文再未出现**，两个空间之间**从未给出定量关系**。桥声明了，没走。
- **2605.00741 ○ 仍未核**（PDF 下载中断）。**引用前必须自核，否则删掉。**
- ~~2605.29816~~：初检未见"连续密度支配"与离散编辑的直接矛盾，**降级，暂不使用**。

#### 4.4.4 可正面接续的对手：LLMCert-T ✅

原文已逐字核实（§1 与 §5）：

> "tool metadata is discrete text and JSON schemas with **no natural perturbation
> radius**, ruling out standard continuous-input certification"
>
> "Certified robustness is well developed for continuous classifiers under bounded
> perturbation sets, but **tool metadata has no $\ell_p$ analogue**: the input space is
> discrete and combinatorial, perturbations are semantic, and the pipeline is
> non-differentiable."

**它把话说了一半**（*metadata* 没有 ℓp 类比，所以走统计证书），**我们接下半句**：
参数**取值**不是 metadata，它常常有数值/序结构，**可以算**——但今天既没有连续证书
也没有离散证书。

### 4.5 一句永久禁令

**不得写"Lipschitz 框架预设连续性"。** LipsLev（2501.13676, ICLR 2025 ○）就在
Levenshtein 距离上定义了 Lipschitz 常数；Hybrid Randomized Smoothing（2605.12876,
ICML 2026 ○）统一离散-连续输入。

正确表述：**agent 可靠性这一支继承的是 $\mathbb{R}^d$ 上那套机器，而文本侧已有的
离散化成果没有被搬过来。**

### 4.6 baseline 清单（实验用）

① CertDR 式 union bound（✅ 已跑，3.12）；② 连续 Lipschitz 界 $L\cdot\varepsilon$
（已跑 M1，恒为 0）；③ 输出跳变筛查（已跑，序关系上 corr +0.11）；④ 经验 Monte Carlo
扰动；⑤ schema 约束检测（Gecko 式规则检查，无证书）；⑥ role-stratified CRC
（按后果分层 vs 我们按**决策几何**分层——需给一个两者判定不同的例子）。

## 5. 叙事蓝图（从这条谱系的 intro 里逆向出来的 7 beats）

> 本节是**写作蓝图**，不是内容。它来自逐字读 8 篇认证/agent 论文的 intro + contributions
> 以及 5 篇金融 agent 可靠性论文。参考文献清单见 `references.md`。

### 5.1 规范弧：认证论文的 7 beats

| Beat | 做什么 | 该谱系的典型句型 |
|---|---|---|
| **B1 既成事实** | 不写"很有前景"，写"**已经是基础设施**"。给具体接口/产品/协议名 | "X **are now a primary interface** between agents and the world" |
| **B2 命名扰动面** | 定义一个**微小、自然、合法**的扰动，并指定**现实的施动者** | "metadata can be written to optimize for retrieval **rather than for utility**" |
| **B3 覆盖不可能** | 论证穷举/覆盖在**原理上**做不到。**整篇说服力的支点，最常被漏** | "…**whose number is exponentially large**" |
| **B4 点估计不够** | 经验 benchmark 为何不足以支持部署 | "**They cannot distinguish a system that fails rarely from one that fails often**" |
| **B5 继承—断裂** | 认证已存在，但只覆盖连续输入/分类输出。我的对象破坏了那个前提 | "prior certification algorithms have primarily focused on **the simpler** classification task" |
| **B6 定义正确的量** | 造新量，用**输出的消费方式**论证，**不用数学优美论证** | "users mainly care about top ranked results → **Certified Top-K Robustness**" |
| **B7 可计算化 + 一个数** | 给可执行过程 + 一个记得住的数，并说明**这个数在前人框架下算不出来** | "87.35% on BERT, **on which previous certified robust methods are not applicable**" |

两条几乎必现的规律：
- **B4 与 B5 之间永远隔着一个"因此"**（Therefore / To escape this arms race / We therefore
  want）。整篇的说服力全压在这个连接词上。
- **B6 的量必须带 qualifier**（Top-K / Satisfaction / under a declared specification）。
  没有 qualifier 的量会被当成"你只是换了个名字"。

### 5.2 我们的排布

| Beat | 我们写什么 | 素材 |
|---|---|---|
| B1 | 金融 agent 已在生产环境调结构化数据 API | FinMCP-Bench："production financial agents … **33 real-world scenarios**，65 financial tools via MCP" |
| B2 | **合法用户在合法 schema 下填错一个离散枚举值**——不是攻击。**机制：绑定信号被符号偏好压过（阶段 A）** | `period="quarter"→"fy"`；施动者是 agent 自己；3.13 的绑定结果 |
| B3 | **66–72% 跃迁、100% schema-valid、连续界报零** | **我们的 Phase-0 数据。必须搬到 intro，不能留在实验节** |
| B4 | 现有 benchmark 给点估计，不能支持部署阈值 | 整段仿 LLMCert-T |
| B5 | **双 gap** | 对认证谱系：**参数层没有 ℓp 类比**；对 benchmark 谱系：分工句 |
| B6 | 定义 ρ 与 κ，**并显式解释方向** | 2.4/2.4b |
| B7 | 报**两个量之间的 gap**：ρ **+0.851** vs jump **+0.110** | 3.10/3.11 |

**B3 的位置是这次最大的修正。** 我们一直把 66–72% 当实验结果放第 3 节，但按这条弧它是
**intro 的支点**。而且我们的 B3 比 SAFER 的更强、方向相反：SAFER 说"邻域大到 $10^{31}$
所以穷举不可能"；**我们说邻域小到只有 3 个，但连续界对它报零——枚举在这里不是不可能，
是没人做**。

**B5 的缝隙比我们以为的窄，必须精确**：LLMCert-T 已在**工具层**论证了"no natural
perturbation radius"；ToolRobustBench 已把 `argument binding` 列为独立 stage；MVTY 已
测出参数类幻觉掉 >12%、工具选择类掉 <8%。**没人在参数层论证离散性本身造成覆盖缺口**
——这是我们唯一干净的 B5，一个字都不能写宽。

### 5.3 赌注怎么立：六条硬规则

**最反直觉的发现：整条认证谱系（CertDR / SAFER / erase-and-check / RobustRAG）全文
一次都没提过金融或医疗。** 它们用**产品名代替行业名**（"Bing Chat, Perplexity AI,
LangChain, LlamaIndex"）、**带出处的真实事故代替假设**（"suggesting applying glue to
pizza (BBC, 2024)"）。

1. 用 `can / may / could`，**绝不用 `will`**
2. **只举一个**后果，不排比灾难
3. 每个赌注句**挂一个引用或一个带来源的真实事故**
4. 加一个**收窄范围的从句**（越窄越可信，而且往往更吓人）
5. 用**不可逆 / 无法重试**当放大器，**不用金额**
6. 把风险绑在**测量不足**上（"we cannot currently tell whether…"），不绑在损失规模上

**可直接改写的句式**（CryptoAnalystBench，三句排比、三个情态、零金额）：
> "a hallucinated **TVL figure may** lead to misestimated protocol risk; an incorrectly
> interpreted yield forecast **could** result in flawed investment allocation; a missed
> protocol update **might** cause failure to anticipate additional risk."

我们的版本应当是：`一个具体的离散参数错误 → 一个具体的、可命名的分析错误`，**停在
决策，不往损益推**。

### 5.4 金融的角色：仪器，不是目的

金融 agent 那批论文（CAIA、CryptoAnalystBench）都花**整段**论证"为什么这个域适合测
可靠性"——有 ground truth、不可逆、时间敏感、数据密集。这是最有效的**去交易化**手段。

**三条纪律**：
- 指标只用 accuracy / error rate。**Sharpe/ARR/MDD 一律不出现**（2502.15865 直接把它们
  划进"不足以捕捉风险"那一栏）
- 因果链**停在决策**（"misguided decision to invest"），不推到 P&L
- 如果被质疑"你是不是在做 alpha"，引 Profit Mirage（2510.07920）最省力

### 5.5 "我们的量才对"怎么说而不像攻击

**从来没有人说前人错了。** 三种句型：

**P1 — 从输出的消费者出发（最有力）**：
> `在<领域>，公认<使用者只消费 X>。[行为证据]。[连现有指标都集中在 X]。因此 <新量>。`

全程只谈使用者行为，**一个字都没评价前人的量**。我们的版本：agent 的下游是排序/选择
决策 → 决策只消费**相对顺序** → 因此该认证的量是相对的（ρ）。

**P2 — 结构不匹配，不是质量问题**：把差异写成**成对属性对照**（离散 vs 连续、排序
vs 标签），不写好坏。`simpler` 这个词同时完成"前人是特例"和"我更难"，却像在夸对方。

**P3 — 分工声明（最安全）**：
> "These works **document specific failure modes**, **while** we **return** …"

外加一招**自我降级式定位**（LLMCert-T）：主动把主张调低一档，换"你不能拿 ℓp 认证的
标准来打我"。我们同样需要——我们给的不是 ∀-保证。

### 5.6 必须控制掉的混淆（审稿人一定会打）

MVTY 发现：**参数描述缺失比工具功能描述缺失伤害更大**。

这既是我们的动机引用，**也是必须控制的变量**——否则审稿人会说"**你测到的是 schema
质量，不是离散性**"。真实 agent 实验里，工具描述/参数描述的完整度必须作为控制变量
固定或分层。

### 5.7 Limitations 必须独立成节

2024 年后没有独立 Limitations 节会被拒。抄 ToolRobustBench 那招——**把"测量原则可
外推"和"绝对数值只适用于本环境"分开写**：

> "**We expect the measurement principle** … to transfer broadly … **By contrast,
> absolute success rates … are more specific to our controlled local setting.**"

再抄 erase-and-check 的三步迎击法（全套材料里最值得抄的一段）：
**承认不做 → 论证不该做 → 但仍然给经验证据。**

### 5.8 两个仍然好用、但已降级的叙事资产

**（a）虚假安全感。** 原来是我们的"最强钩子"，现在降级为 **B3 的修辞包装**——因为
"连续界对离散失效"是**已知前提**（见 4.1）。可以这样写而不越界：连续界报零**不是
疏漏而是定义使然**，其后果是 agent 拿到一个**看起来被认证过**的输出。**不得声称这是
我们的发现。**

**（b）D4 负结果。** 仍然是好资产，但**必须限定在序关系决策上**（见 3.11：输出跳变在
阈值决策上达 +0.861）。

### 为什么"负结果"反而是最强的动机（D4 的失败）

变体 A 的实验里有一个**对论文有利的负结果**，它直接就是核心主张的机制证据：

> **输出跳变幅度不能预测决策翻转**（逐实例 corr −0.12；4 宇宙 48 格重测 corr
> **+0.11**，仍基本无信息）。决策翻转是跨 symbol 的相对结构变化——所有 symbol 的 EPS
> 同向跳 3–4 倍，排名重排方式无法被任何单查询输出统计量预测。TSLA 跳 93% 排名几乎不
> 变，AMZN 跳 3% 排名动 7 位。
>
> 3.10 给出了这条负结果的**原因**：翻转条件 $|\Delta\log r| > |\Delta\log q|$ 里
> **根本没有绝对幅度**，只有缩放离散度与标的间距之比。输出跳变不是"预测得不好"，
> 而是**测错了量**。

**区分两种负结果**：
- **坏负结果**：我们的方法没起作用（如"枚举筛查器漏 50% 决策翻转"）→ 论文死了。
- **好负结果（D4 这种）**：**别人的方法/直觉**被证明是错的，而**我们的方法**恰好补上。
  D4 是"输出跳变不能预测决策翻转"——打的是**现有直觉**的脸，不是我们的脸。

**为什么 D4 失败反而让变体 A 最强**：D4 证明的正是论文的核心主张——**"输出看起来稳
（跳变小）≠ 决策安全"**。这不是论文的绊脚石，它是论文论点本身的机制证据。叙事是完整
的"打脸-救场"结构：
1. **先证明直觉错了**（D4 负结果）：agent 不能靠输出稳定性判断安全。
2. **再给出正确做法**（枚举筛查器正结果）：对每个离散邻居重算决策、看是否翻转，
   100% 抓到（输出跳变筛查只 recall 69%）。

**对比**：变体 B、C 全 PASS 但**平淡**——B 是"审计能列出危险组合"（预期内），C 是
"端点稳健性不同"（有用属性），都没有"啊哈"时刻。**A 是唯一有"啊哈"的**：D4 让读者
"咦，输出跳变居然不能预测决策翻转？"——这个惊讶就是论文的钩子。负结果给了戏剧性
（motivation），正结果给了价值（solution）。

## 6. 应用场景（故事定位，已实验验证）

核心钩子：**现有认证在主动误导 agent**——连续界对离散翻错给出"零误差"，agent 过度信任
一个实际跳变 66–72% 的输出。混合界修复的不是"多一个界"，而是"一个会骗人的认证"。

三个变体（定位，不是小实验），**全部已用 `mixed_scale.jsonl` 实验验证**（见
`README_variants.md`，$0、无新采集）：
- **变体 A — 决策前筛查器（主推，证据最强）**：agent 把工具输出用于下游决策前，用 S_mix
  跑一遍，标记"这个查询对离散参数敏感"，据此复核参数/重新查询/降级置信度。
- **变体 B — 接口灵敏度审计（最省）**：工具开发者用它对 API 做自动化 QA，枚举离散参数
  组合，生成"哪些参数组合会跳变"的报告。
- **变体 C — 工具选择/路由信号**：agent 用 S_mix 判断哪个工具对这个查询更稳健。

### 三变体实验结果

**变体 B（接口审计）— 全 PASS。** 420 跃迁重组为危险清单，能**区分**危险/安全组合：
quarter→fy 与 statement 替换危险（D_G 53–100%），quarter→all 在多数端点安全（D_G=0）。
审计不是"全都危险"的废话，而是能筛出真正危险的参数组合。

**变体 A（决策筛查器）— v1 部分失败 → v2 全 PASS，且带一个真正的发现。**
决策任务"按 EPS 排名选最贵 3 个"：
- v1：80% symbol 排名变、top-3 翻转 2/3、28.9% 两两比较翻转（D1-D3 PASS）。
- **v1 D4 FAIL（这是发现）**：EPS 跳变幅度**不能预测**排名变化（corr −0.12）。因为决策
  翻转是**跨 symbol 的相对结构变化**——所有 symbol 的 EPS 同向跳 3–4 倍，排名重排方式
  无法被任何单查询输出统计量预测。TSLA 跳 93% 排名几乎不变，AMZN 跳 3% 排名动 7 位。
  **"输出跳变小 ≠ 决策安全"**——直接支撑"认证给虚假安全感"的核心主张。
- v2：正确的筛查器是**枚举重算**（对每个离散邻居重算决策、看是否翻转），即 S_mix 的
  D_G 思路从输出空间延伸到决策空间。输出跳变筛查漏 31% 的决策翻转（precision 73%、
  recall 69%），枚举筛查 100% 抓到（E1/E2/E3 全 PASS）。

**变体 C（工具路由）— 全 PASS。** 不同端点对同一替换（period=quarter→fy）敏感度不同：
key-metrics 53%（最稳）、enterprise-value 87%、fundamentals 97%（最不稳）。R1 端点有差异
（spread 44%）、R2 三个不同敏感度级、R3 排名跨 symbol 稳定（20/20 symbol 中
key-metrics ≤ fundamentals，100%）。agent 可据此路由到最稳的工具。

### 结论：变体 A 是主故事，B/C 作辅助支撑

- **A（主故事）**：有最强的研究发现——**D4 的失败**（输出跳变不预测决策翻转）是真正
  反直觉的结果，直接支撑"认证给虚假安全感"的论点；枚举筛查器是可落地的工具。负结果
  当 motivation，正结果当 solution。
- **B（辅助支撑）**：接口审计证明"哪些参数组合危险"可自动化生成，为 A 的筛查器提供
  底层能力（筛查器需要先知道哪些参数组合会跳）。最便宜最干净，但本身是 QA 报告，
  不独立成研究结果。
- **C（辅助支撑）**：工具路由证明 S_mix 能排序端点稳健性，为 A 提供"选哪个工具更稳"
  的补充能力。干净且 PASS，但"端点稳健性不同"更像有用属性，不是惊人结果。

**论文结构**：A 是主线（motivation 用 D4 负结果，solution 用枚举筛查器），B 和 C 作为
支撑证据放在 experiments 或 appendix，证明 S_mix 的能力不止于单个筛查器，还能做接口
审计和工具路由——增强方法的通用性。

**变体 vs 小实验的关系**：变体是论文的贡献定位/故事（intro/motivation），小实验是验证
定位的证据（experiments）。同一个变体配不同实验，同一个实验服务不同变体。选变体 =
选故事，然后补对应的实验。

## 7. 局限与未来工作

### 局限
1. **测的是输出跃迁，不是决策跃迁**。D_G 大 ≠ 改变下游金融决策。往金融框（变体 A）需要
   补"翻错 period 是否改变估值/筛选结论"的实验。
2. **D_G 在枚举邻接上算**，不是完整语义图。更全的图是后续工作。
3. **测输出跳变，不测 LLM 是否真的会犯**（generator relevance 是单独探针，已补）。
4. **owner-earnings 端点在消融里数据不足**（S1 只列了 3 个有数据的端点）。
5. **阶段 A 是行为层绑定假设，不定位内部机制**。$d>B$ 是恒等式；$d$ 是行为交互，
   不自动对应内部模块。因果证据需阶段 C 激活干预（未做）。
6. **阶段 A 的 $\lvert a\rvert$ 可能混入位置效应**（模型在参数位置不情愿输出裸符号）。
   这不改变主线结论（绑定不支配、符号偏好压过），但绝对数值只适用于本环境。
7. **阶段 C 的激活干预是暗示性而非干净的因果证据**。晚期层 patch 的效应方向不
   完全一致（部分 patch 朝 source 方向、部分朝反方向），且随机向量对照本身也有
   一定效应（普遍破坏成分）。real patch 超过 random 2–3 倍，但方向性不完美。
   单次 patch 成功不等于完整因果识别（理论稿 §5）。机制层主要靠阶段 A 的行为结果
   支撑，阶段 C 是补充证据。
