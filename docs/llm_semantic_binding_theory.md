# LLM 合法参数错误的理论框架：语义绑定、输出偏好与实际读出

日期：2026-09-21

状态：理论工作稿与机制验证规范；不是已经得到实验支持的机制结论。

## 1. 研究范围与核心问题

本稿沉淀围绕现有 period=quarter/FY 现象形成的 LLM 层面解释。有限篇幅集中于：为什么模型能够生成 schema-valid、正常执行、却不符合用户明确时间要求的参数？

核心假设是：**任务语义可以被模型表示，但它与工具参数的绑定未必充分控制实际生成；非绑定的输出偏好可能压过正确绑定信号。**

这里区分三个层次：

1. 请求语义识别：用户究竟要求季度还是全年。
2. 语义绑定：根据当前 schema，将请求含义映射到正确参数符号。
3. 实际读出：内部信息是否真正影响最终参数字符串。

本文不把误差传播的代数分解当成模型内部机制，不以新增领域、联合错误类型或更多 benchmark 替代机制挖掘。已有工具数值和决策翻转结果提供动机与后果证据，不能证明上述生成机制。

本稿是新增研究主线工作稿，不表示旧 `paper_framework.md` 中的全部结论已被复核。尤其不能由本文推出“固定离散参数的连续界宣称其他离散参数也安全”，不能继承未经自然轨迹验证的真实错误率或零错误筛查保证。

## 2. 正确操作是一个关系，而不是某个固定字符串

固定股票、字段及其他调用参数，只研究 period。令：

- $u\in\{-1,+1\}$ 为请求语义，分别表示全年、季度；请求必须明确且标签无歧义。
- $z\in\{-1,+1\}$ 为输出符号，分别表示 B、A。
- $v\in\{-1,+1\}$ 为 schema 映射方向。

当 $v=+1$ 时，A 表示季度、B 表示全年；当 $v=-1$ 时，A 表示全年、B 表示季度。适配器把符号转换为原 API 的 quarter/FY，金融数据和实际操作不变。

正确参数为：

$$z^*=uv.$$

| 请求 $u$ | 映射 $v$ | 正确输出 $z^*$ |
|---|---|---|
| 季度 +1 | A=季度 +1 | A +1 |
| 季度 +1 | A=全年 −1 | B −1 |
| 全年 −1 | A=季度 +1 | B −1 |
| 全年 −1 | A=全年 −1 | A +1 |

分别掌握 u 和 v 不等于正确计算其关系。理想语义映射还应满足符号重命名等变性：对一致重命名 schema 与输出的置换 $\pi$，

$$a^*(I,\pi S)=\pi(a^*(I,S)).$$

这是正确解的性质，不是预设真实 LLM 已具备的能力。符号重编码是机制鉴别手段，并非声称真实 API 原本使用 A/B。必须同时报告原生 quarter/FY 接口，以检查人工接口是否引入不同的困难。

## 3. 输出对数优势的精确分解

对固定的其他上下文，比较两个合法候选调用的条件概率。令

$$\ell(u,v)=\log\frac{P_\theta(a_+\mid I_u,S_v)}{P_\theta(a_-\mid I_u,S_v)},$$

其中 $a_+,a_-$ 除目标参数外完全相同，并包含统一的终止边界。候选可能包含多个 token，应使用完整序列对数概率之和；不得把多 token 字符串当成一个 token，也不得把平均 token 分数误称为序列概率。

对四个有限的对数优势，二值输入上的完整展开是：

$$\boxed{\ell(u,v)=a+bu+cv+duv.}$$

各系数可唯一恢复：

$$a=\frac14\sum_{u,v}\ell(u,v),\quad b=\frac14\sum_{u,v}u\ell(u,v),$$

$$c=\frac14\sum_{u,v}v\ell(u,v),\quad d=\frac14\sum_{u,v}uv\ell(u,v).$$

解释：a 是固定符号偏好；b 是请求主效应；c 是 schema 主效应；d 是方向正确的请求×映射交互项。

**这是饱和的二因子/Walsh 展开，是恒等式，不是拟合发现，也不是本项目的新数学贡献。** 主效应包含具体表述、位置、符号等可能因素；不能未经干预直接称它们为“训练频率先验”。同样，d 是行为上的绑定一致性交互，不自动对应某个内部模块。

所有系数最初都应按匹配上下文逐例计算。先平均不同任务的 logits 再计算错误，会掩盖任务异质性；平均 log-odds 也不等于平均概率的 log-odds。

## 4. 命题：正确绑定何时支配参数选择？

先限定解码器：在上述两个候选中选择序列概率较大者，故 $\hat z=\operatorname{sign}\ell(u,v)$。这不是完整自由生成的普遍模型。

定义正确答案方向上的间隔：

$$M(u,v)=uv\ell(u,v)=d+a uv+bv+cu.$$

无平局时，

$$\boxed{\hat z=z^*\iff M(u,v)>0.}$$

令

$$B=\max_{u,v}\{-a uv-bv-cu\}.$$

**命题 1：四种请求—映射组合全部严格正确，当且仅当 $d>B$。**

证明：

$$\min_{u,v}M(u,v)=d-B.$$

四种组合全部严格正确等价于最小间隔为正。等号意味着至少一例候选概率平局，须单独约定 tie-break。证毕。

由于 $B\le |a|+|b|+|c|$，一个更保守的充分条件是：

$$d>|a|+|b|+|c|.$$

例：$a=2,b=c=0,d=1$。虽然 d 为正，但 $\ell=2+uv>0$，模型始终选择 A，在四种平衡组合上错两种。这个例子证明“存在正确方向的交互项”与“实际参数错误”并不矛盾；它不证明真实 LLM 使用了独立的绑定组件。

若从两个候选的归一化分布进行温度 1 采样，则：

$$P(\hat z\ne z^*\mid u,v)=\sigma(-M(u,v)),$$

其中 $\sigma(t)=1/(1+e^{-t})$。温度、截断采样、完整调用生成会改变实际分布。候选打分结果与自由生成错误率必须分开报告。

## 5. 从行为到 LLM 内部：表示存在不等于实际使用

在单 token 二候选、共同生成前缀的简化读出情形，令 h 是送入最终线性词表读出的状态（例如完成最终归一化后），w 是两个候选的输出权重差，β 是偏置差：

$$\ell(u,v)=w^\top h(u,v)+\beta.$$

对四个状态同样可作精确展开：

$$h(u,v)=h_0+u h_u+v h_v+uv h_{uv}.$$

于是：

$$\boxed{d=w^\top h_{uv}.}$$

这不同于 $d=\|h_{uv}\|$。即使 $h_{uv}\ne0$，若 $w^\top h_{uv}=0$，该交互分量在此输出比较中没有贡献。

类似地，即使探针 r 能使 $r^\top h$ 预测 u，也不意味着模型实际读出能给出 uv。探针方向不等于模型实际使用的输出方向。因此：

$$\boxed{\text{信息可解码}\not\Rightarrow\text{信息被用于正确行动}.}$$

这是可解释性证据的边界，不是声称模型一定理解但不用。h 的四项展开仍然是代数，不能直接把 $h_{uv}$ 视作已识别的独立神经回路。

对于多 token 候选，需要分别计算各前缀状态贡献；上述单个 w、h 的公式不再直接适用。可选择单 token 中性符号做简化机制分析，但必须回到原生参数验证外部有效性。

### 因果验证要求

用仅改变请求语义或映射的成对输入进行激活替换，检验相关位置/层的干预是否按关系 uv 改变参数偏好，同时保持股票、字段等其他输出稳定。至少需要：

- 随机位置、无关语义、等强度随机向量对照；
- 双向干预、保留模板测试及候选全概率比较；
- 破坏与恢复证据相互印证，防止把一般生成损伤称作特定机制；
- 对分布外激活拼接保持谨慎，单次 patch 成功不等于完整因果识别。

如果只有黑盒 API，应停留在行为层面的绑定假设，不声称定位了内部机制。

## 6. schema-valid 为什么不推出任务正确？

合法性约束是：

$$\hat z\in\mathcal Z_{\mathrm{valid}}=\{-1,+1\}.$$

语义正确性是：

$$\hat z=uv.$$

因此：

$$\boxed{\hat z\in\mathcal Z_{\mathrm{valid}}\not\Rightarrow\hat z=uv.}$$

前者约束集合成员资格，后者约束请求、schema 和输出的关系。只排除非法符号并不保证 d 支配其他项。因此调用可以合法、工具可以正常执行，而任务语义仍然错误。

这不是说任何受约束解码都无效：若系统额外获得可靠的目标语义并把正确映射强制写入约束，就能解决此二值选择。这里讨论的只是 schema 合法集合约束。

## 7. 与现有项目证据的关系

已有 quarter/FY 输出变化与决策翻转说明“选错合法参数可能有实质后果”。它们不能区分以下竞争解释：请求未被理解、schema 映射未知、绑定失败、输出偏好或采样噪声。

本稿机制假设需要新的模型侧证据，但保持原任务与原参数不变，不通过增加更多现象来扩大文章范围。

尤其禁止以下跳步：

- 由 next-token prediction 推出所有错误必然来自词频先验；
- 由口头回答正确推出原调用时内部语义已经正确；
- 由线性探针准确率推出模型实际使用了该信息；
- 由 d 大推出存在独立 binding-ID 神经机制；
- 由四项展开能拟合四个数推出获得了理论发现；
- 由工具反事实回放推出真实模型生成错误的频率或原因。

## 8. 最小机制验证协议

### 阶段 A：建立可识别的行为对照

1. 固定工具、股票、字段和数据快照，使用明确季度/全年请求；排除语义歧义样本。
2. 为每个基础任务生成完整的 u×v 四格，随机化顺序。用多个中性符号对，平衡位置、token 长度和示例形式。
3. 同时保留原生 quarter/FY 接口和对照适配接口；确认后端操作严格等价。
4. 获取完整候选 log-prob，逐任务计算 a,b,c,d、四个 M 和 B。自由生成另外评估，不混用选择规则。
5. 报告逐任务分布与任务级不确定性；划分请求模板/符号组合的保留集。四格恒等式无需用显著性证明。

### 阶段 B：区分竞争机制

- 固定操作含义改变符号/顺序，检查哪个分量随干预变化；不能先把偏差来源命名为词频。
- 对请求识别、显式映射和实际调用分别测试，辅助定位失败环节；这些测试会改变任务，不能当作原轨迹内部状态的直接观测。
- 分清 $M<0$ 的选择错误与 $M>0$ 时采样产生的错误；不把后者一律解释为绑定失效。

### 阶段 C：在开放权重模型上获得因果证据

实施第 5 节的成对激活干预。在保留上下文中检验参数控制的选择性和方向性。若干预只能普遍提高/降低输出质量，不能支持特定绑定解释。

停止或收窄条件：重编码效应主要来自人工接口陌生性；原生错误主要是请求理解失败；正确间隔已经很大而问题只来自采样；或内部干预不支持绑定信号控制假设。不得为保留故事而忽略这些结果。

## 9. 文献定位与贡献边界

1. Feng, J. & Steinhardt, J. **How do Language Models Bind Entities in Context?** ICLR 2024。研究实体—属性绑定与激活干预，在部分模型/任务中发现 binding-ID 表征，也报告非普适性。本文借用其机制问题和因果方法，尚未证明工具语义绑定采用同一机制。[正文](https://arxiv.org/html/2310.17191v2)
2. Zhao, T. Z. et al. **Calibrate Before Use: Improving Few-Shot Performance of Language Models.** ICML 2021。研究少样本预测中的输出偏好与上下文校准。它支持对非语义输出偏好的考察，不证明本项目 quarter/FY 的具体偏好来源。[正式论文](https://proceedings.mlr.press/v139/zhao21c/zhao21c.pdf)
3. Meng, K. et al. **Locating and Editing Factual Associations in GPT.** NeurIPS 2022。提供事实预测中的因果追踪/编辑研究范例。其事实回忆结论不能直接移植到工具绑定。[作者项目页](https://rome.baulab.info/)

二因子分解、线性读出、间隔条件与合法性/正确性区分本身均不主张数学首创。可形成贡献的部分是：在原工具任务上识别一个具体失败机制，用语义保持干预与内部因果证据排除竞争解释，并说明该机制如何产生已观察到的合法错误及其后果。

## 10. 后续工作统一表述

当前可以说：“我们提出并形式化检验语义绑定不足以支配参数生成的假设。”

当前不能说：“我们已经证明 LLM 工具错误源于绑定机制失败。”

论文主线暂定为：**语义关系如何被表示、如何控制参数生成，以及这种控制何时失效。** 现有决策敏感性分析作为后果层支撑；除非获得足够证据，不再把理论中心转移到无关的新现象、泛化认证框架或新的应用领域。
